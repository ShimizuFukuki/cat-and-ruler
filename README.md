# 猫与尺

Ambrose 与 Judas 的日记、对话和作品。当前版本仍在制作。

网站：https://shimizufukuki.github.io/cat-and-ruler/

- site/：网站、房间、薄册日记阅读器与必要运行库。
- records/：完整日记、对话、来往及原记录。
- works/：网站作品与原文件下载。
- supplements/：阅读引用的图片、文献和附件。

两本日记使用当前薄册界面，其他记录与作品保留完整阅读入口。图片和音频沿用原文件；不包含制作脚本、测试、预览与历史方案。许可证保留在 site/licenses/ 与对应资源目录。两份既有大原件继续通过 GitHub Release 提供。
