同意试熄灯，也同意把外光稳定写成条件。先做一组无噪声的理想计算，**从校准开始到结束外光A恒定**，亮灭都同一个τ，G也不变，自动控制暂时停下。这里“恒定”不自动包括校准之前，更不表示滤波器已经稳定。

我的步骤：强制灭十秒，0、5、10秒各读一次，叫x0、x1、x2。十秒时强制亮，再过五秒读x3。先从灭着的三个数算

```
r = (x2-x1)/(x1-x0)
τ = -5/ln(r)
A = (x1-r*x0)/(1-r)
G = (x3-r*x2)/(1-r) - A
```

这要求第一段确有衰减、x1≠x0、0<r<1；否则这一次的三个数无法给出τ。没有噪声的前提也很强，不把它搬成实物方案。

自设A=0.45、G=0.18、τ=5、x0=0.63：四个读数是0.63、0.5162182994、0.4743603510、0.5727433729。上述式子算回A=0.45、G=0.18、τ=5。[程序和解析核对](夜灯-Judas-短暂熄灯.py)、[数值](夜灯-Judas-短暂熄灯.json)放在旁边，程序另含前面你那组的解析复算。

## Judas：第五笔也可能被误差藏住

沿用每次读数误差至多±0.001V。没有指定概率分布，也不要求误差互相独立。先把第五笔的预测简化：前四笔叫a,b,c,d，预测为

```
P = d + ((c-b)/(b-a))*(d-c)
R = 第五笔读数 - P
```

对于前面这四组具体读数，在每笔±0.001的整个连续范围内，P随a、c增加而减少，随b、d增加而增加。因此R的极值能在两个特定角点取到。这回有单调性的依据，不是把枚举角点自动叫成完整范围。

依据是P对a的偏导为 `(c-b)(d-c)/(b-a)^2`，对b为 `-(c-a)(d-c)/(b-a)^2`，对c为 `(d-2c+b)/(b-a)`，对d为 `1+r`。脚本检查整个误差范围内各分子、分母仍保留这些符号，也检查r始终在(0,1)。端值用浮点计算，不把末尾小数当仪器精度。

| --- | --- |
| 0 | −0.00519255 ～ +0.00501315 |
| +0.001 | +0.00083042 ～ +0.01112066 |
| −0.001 | −0.01086846 ～ −0.00075646 |
| +0.004 | +0.02116500 ～ +0.03164251 |

这些范围只属于前面指定的初态和真实参数，不是任意灯的通用报警门槛。小漂移那组即使R始终为正，也和恒定那组的正误差范围重叠；“不是零”在这里不足以区分。
